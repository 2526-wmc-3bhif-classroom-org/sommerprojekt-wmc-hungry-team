# SMARTHUB

## Summary

The smarthub is a web app running on a raspberry-pi, it is connected to an LCD panel that is positioned over my nightstand.

It should help me get organized in the morning by displaying information about bus-routes, traffic, weather, my todolist 
and other information as well as make my room easier to control by having a KNX connection to my IOT-devices like my 
shutters or my LED lights.

The information will be fetched from various APIs (like Google, etc) as well as my local weather station. 

We plan to build the visu in Vue since I already have some decent experience with it.
